# Flutter Agent-Skills Research Report

**Date:** 2026-10-01 · **Scope:** installable agent skills for a Flutter desktop/mobile + Rust-FFI workflow.
**Priorities (in order):** testing → architecture → lint/static analysis → project structure & scalable codebases → performance (desktop/mobile; web unimportant) → Rust+Flutter FFI (flutter_rust_bridge-style) → Dart isolates & concurrency.

**Method.** Everything below is grounded in the vetted research batch supplied with this task: ~390 candidate entries, each carrying its own read/fetch/clone evidence (file sizes, line counts, HTTP statuses, git commits). Nothing was installed or re-fetched while writing this report; install commands are listed per skill but **not executed**. After merging duplicate candidate ids, the batch yields **273 install recommendations**, ~30 "already covered" duplicates, and ~230 rejections.

---

## 1. Verdict

The ecosystem is **deep exactly where your priorities are strongest and thinnest exactly where they are most specialized**.

- **Testing (#1) is the richest area.** The surviving official `dart-lang/skills` testing trio (unit tests, mocks, coverage) is maintained and current; LeanCode ships Patrol skills from the Patrol authors themselves; and there are at least four credible full-suite doctrines (VGV, zakariaf, 22Teikk, kao273183). Widget/integration/golden/mocking/coverage/flakiness are all covered by multiple substantive options.
- **A warning that shapes everything else:** the official Flutter and Dart orgs **gutted their topic skills in March–June 2026**. `flutter/agent-plugins` deleted its testing, performance, concurrency, architecture, caching and state skills (commits 094df61, 130378c, 2e24431, a40929a); `dart-lang/skills` cleared almost everything on 2026-04-22. Many skills.sh listings for these (flutter-performance 9.1K installs, flutter-testing-apps, dart-concurrency-isolates…) are **stale ghosts** — uninstallable as named. Do not install by those ids.
- **Architecture, lint, and structure** are well served by maintained community suites (VGV, zakariaf's 40-skill suite, evanca, gabuldev, ariaramin, plus a complete 22-skill Riverpod reference family from Serverpod).
- **Rust+Flutter FFI is the thinnest priority.** The official `fzyzcjy/flutter_rust_bridge` repo ships only maintainer-internal skills (every command runs `./frb_internal`, which does not exist in your projects). Usable FRB guidance exists only in app repos — Hoplixi (~103KB of references), openmls_dart, onde, telepathy, Genesix, JA_Route — real and deep, but unofficial and partly project-flavored. Same story for Rinf (plain notes, no SKILL.md packaging for half of them).
- **Desktop-specific skills are scarce** (one true desktop skill found); desktop coverage otherwise arrives as sections inside performance skills. Several strong skills are written in Chinese/Japanese/Korean/Spanish/Portuguese — flagged per entry.

**Top 5 picks** (one command each):

| # | Skill | Why |
|---|-------|-----|
| 1 | `leancodepl/patrol@patrol-write-test` | Patrol E2E rules from the Patrol authors — squarely priority #1 |
| 2 | `zakariaf/flutter-skills@testing-strategy` | The best overall testing doctrine (suite-shaping, fakes, coverage floors) |
| 3 | `ariaramin/flutter-skills@flutter-performance-jank-optimization` | Evidence-driven jank workflow with explicit desktop coverage |
| 4 | `poorgramer-zack/dart-expert-skills@flutter-isolate` | The most exact isolates/concurrency skill found (346 lines) |
| 5 | `vartec-chs/Hoplixi@flutter-rust-bridge` | The deepest flutter_rust_bridge v2 reference set (~103KB) |

## 5. Gaps — where no good skill exists

1. **An official flutter_rust_bridge usage skill.** The upstream FRB repo ships only maintainer-internal skills (all `./frb_internal`-based), so the best FRB guidance available is unofficial and scattered across app repos (§2.8). Nothing canonical exists for FRB API design + codegen + packaging as one maintained skill.
2. **FRB-for-multithreading/performance tuning.** Every FRB skill found covers codegen mechanics, patterns, or builds; none focuses on the performance/multithreading exploitation of Rust workers under Flutter (thread pools, streaming backpressure across the bridge, benchmarking Rust tasks from Dart).
3. **Maintained official Flutter/Dart-team performance and concurrency skills.** `flutter/agent-plugins@flutter-performance` was deliberately removed (2e24431) and `dart-lang/skills@dart-concurrency-isolates` was deleted in the April 2026 clear-out; the skills.sh pages for both are stale ghosts. Community skills fill the space, but there is no official-maintained option.
4. **Flutter-desktop-specific performance depth.** Exactly one recommended skill has a dedicated desktop performance chapter (ariaramin@flutter-ui-performance-engineering); everything else is mobile-first with desktop as an afterthought, and only one true desktop skill exists at all (sqflite-common-ffi-desktop).
5. **Accessibility testing.** The official a11y skill was deliberately removed (a40929a); remaining coverage is partial (contrast/overflow checks inside widget-golden-and-a11y-testing, the conalyz a11y lint CLI) rather than a dedicated, maintained a11y-testing skill.

**Fallback:** for these five areas, author your own with `npx skills init` — the vetted batch repeatedly shows that the highest-quality skills in this ecosystem are exactly that: single-purpose, house-style skills extracted from real projects.
