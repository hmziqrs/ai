Shipflow graph

Visual companion to shipflow-plan.md (same directory) — the plan is the source of truth; every box below is mined from it. Per-project package: the queue is the project's GitHub Issues via gh; nothing global, nothing outside the project tree.

1. The infinity layer (coordinator + watchdog — never a loop inside a run)

Coordinator (main agent running the shipflow skill)
loop: gh issue list -l pipeline:ready → none: end session (watchdog re-kicks) → found: CreateWorkflow shipflow-queue with subagent_model pinned to the cycle's tier (pro default; flash for label chores), args per plan section 6 → record the typed CycleReport → relaunch for the next issue. Tier-pure node launches, zflow-engine style: the launcher pins the model per node; the script never pins models. Deep-complex areas: coordinator launches zflow-engine mode=implement tier=pro between cycles (no nesting).
Watchdog cron (per-project, notify-only)
every 15 min: ready issues exist AND no .shipflow/cycle-*.md artifact in 30 min → open one pipeline:watchdog issue. The cycle report artifact is the heartbeat. The cron never relaunches an agent session.

POLICY exits, enforced in code (never model judgment): queue empty; pipeline:paused on the pin issue; two consecutive failed cycles; per-area maxRounds cap (default 3); never claim clean while a gate is red.

2. One queue cycle — shipflow-queue.dwf.ts (one run = one model, relaunch-per-cycle)

Claimgh-ops: assign + ready→claimed, re-read to verify the win; branch shipflow/issue-n
→
Triagere-validate actionable; else comment + release + typed end
→
Planplanner emits areas[]; plan-auditor proceeds|fix-plan (max 2 re-plans)
→
Implementimplementer-<area> per area, deps chained; fix rounds reuse the same agent
Gatesliteral allowlist switch in code: npm pnpm yarn bun cargo make go python3 pytest npx git (read-only); non-mutating
→
Previewbuild/dev-server via the same allowlist; URL recorded
→
Browseragent-browser CLI only, --session shipflow-<issue>; no MCP; evidence to .zflow/evidence/
→
Visionflash reads PNGs natively; pro batches ALL screenshots into ONE escalation (cap 3)
PRworld.run("gh", ["pr","create",...]); one commit per green round, ≤400 lines / ≤10 files; never --no-verify; never push a branch
→
Auditsecurity-audit + injection-auditor + fresh blind judges judge-<area>-r<round>; findings confirmed or labelled
→
Mergeonly when code verifies: gates green, audits attached, zero open blocker+major, budget held → gh pr merge --squash --delete-branch
→
Cleanup → Reportlabel done|failed + comment merge sha; typed CycleReport + status board + .shipflow/cycle-n.md artifact (heartbeat)

Declared args: issueNumber, repo, tier (behavior switch; launcher pins subagent_model), task, areas, agentsMd (default "AGENTS.md"), baseSha, maxRounds (3), commit (true), dryRun (false = full cycle except PR create/merge). Script hygiene: strict-safe; no Date.now / Math.random / process / fetch / fs; no nesting; no MCP plugins; AGENTS.md read-first line in every spawned ask.

3. Tier lanes (one model per run — subagent_model is run-wide)

Pro lane — glm-5.3
  • rust-impl (high), svelte-impl (high), fixer (high)
  • perf-engineer (max), qa-writer (high)
  • rust-review (max), svelte-review (max), pr-reviewer (max)
  • security-audit (max), task-planner (max), plan-auditor (max)
Flash lane — glm-5.3-flash
  • copywriter (low), injection-auditor (low)
  • browser-tester (low), vision-judge (high) — vision needs pixels: pro is image-blind
  • issue-triage (low), queue-monitor (low)
  • gh-ops (low), scout (low), pr-merger (low — merge checks run in code)
Code lane — no model
  • gate allowlist switch (world.run literal commands)
  • git discipline (serialized, explicit paths)
  • size budget via numstat vs baseSha
  • POLICY loop conditions + stagnation counters

5. Install shape (phase-0 gate before first run)

Per-project copies only: 20 agents → <project>/.zcode/agents/; workflow → <project>/.zcode/workflows/; 8 knowledge checklists → <project>/docs/agents/. Never ~/.zcode or any global path. Phase-0 verifies: workspace agent discovery (20 shipflow files listed in a fresh session), agent-browser headless with --session, flash-pixel vs pro-image-blind proof, gate allowlist coverage. Labels: pipeline:backlog, ready, claimed, done, failed; pause = pipeline:paused on the pin issue.
