# Design system

Tokens are measured from the reference and renamed. The values below are invented.

## Colour
- `surface-base` light #f7f5f0, dark #15171a.
- `text-primary` light #1d2025, dark #eceef1.
- `accent` light #2f5d8a, dark #7fb2e5.
- Every text pair must reach WCAG 2.2 AA contrast (4.5:1 for body text).

## Type
- Body 16 px / 1.5, table text 14 px / 1.4, headings on a 1.25 scale.

## Space and layout
- Spacing steps: 4, 8, 12, 16, 24, 32, 48 px.
- Breakpoints: 390 px (phone), 768 px (tablet), 1440 px (desktop). Content width caps at 1200 px.

## Primitives
- Button, badge, table, tooltip and combobox. Each primitive is documented with its states: default, hover, focus, pressed, disabled.
