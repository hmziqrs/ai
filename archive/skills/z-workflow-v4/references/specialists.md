# Specialist selection without a new planning phase

The author selects one matching domain persona per writing area from actual available
agent descriptions and project manifests. Resolve absolute paths; project niche personas
live in `<project>/.zcode/agents/`, general orchestration actors globally. Never install niche
agents globally. Native Agent supports registered types only; a workflow must load the
actual persona file through the local kit, not call a file name as if it were a model.

Typical choices: `z-elysiajs-engineer` for Elysia, `z-svelte-engineer` for SvelteKit,
`z-gpui-engineer` for GPUI, `z-tauri-integrator` for Tauri v2, `z-flutter-engineer` for Flutter,
`z-rust-engineer` for Rust. Select relevant framework skills from the session's index; do not
load unrelated auth/database/design systems merely because a persona mentions them.
A required missing expertise/tool blocks that assignment; an optional missing specialist can
use an explicitly named suitable general persona with the limitation recorded. Do not stop
for project setup if no missing capability is needed by this task.

Routine implementation dispatch: task, area contract, worktree, owned/excluded paths,
relevant skills and requested output. Include explicit V4 policy: implement and assemble;
no plan review, audit, QA, tests, screenshots or incidental fixes unless requested. Persona
expertise does not re-enable an old workflow's mandatory audit ladder. Preserve project/user
requirements and tool authority; report genuine conflicts instead of inventing permission.

`z-qa-evaluator`, device verifiers and security auditors are opt-in for requested QA/audits.
Given acceptance criteria can be read directly; `prd-authoring` is needed only for an actual
PRD task. `parity-testing` applies to a requested reference comparison, not an original app.
No UI automatically receives a browser/device lane. When requested, runtime checks receive
correct server/session/data/evidence authority; a read-only source reviewer isn't asked to
run a live mutation it is prohibited from performing.
